# 📊 Marketing Campaign Performance Analysis

An exploratory data analysis and dashboard project focused on evaluating **digital marketing campaign performance** across audiences, campaigns, channels, media types, and traffic sources.

The project uses historical marketing campaign data to understand how marketing spend translates into impressions, clicks, leads, and primed leads.

---

## 📌 Project Overview

Marketing teams need to understand which campaigns and acquisition channels are generating meaningful results relative to their investment.

This project analyzes marketing campaign data to answer questions such as:

* How much was spent across marketing campaigns?
* How many impressions and clicks were generated?
* Which campaigns generated the most leads?
* Which digital sources contributed the most traffic and conversions?
* How does campaign performance vary across different audiences?
* What is the relationship between marketing cost, clicks, impressions, and leads?
* Which channels can be explored further for campaign optimization?

---

## 📂 Dataset

The analysis is based on historical campaign-level marketing data covering:

**January 2017 – February 2019**

The dataset contains **20,680 campaign records**.

### Key Columns

| Column           | Description                            |
| ---------------- | -------------------------------------- |
| `Audience`       | Target audience segment                |
| `Campaign Date`  | Date of the marketing activity         |
| `Campaign Name`  | Name/type of campaign                  |
| `Digital Source` | High-level acquisition channel         |
| `Medium`         | Marketing medium used                  |
| `Source`         | Specific traffic or advertising source |
| `Clicks`         | Number of clicks generated             |
| `Cost`           | Marketing spend                        |
| `Impressions`    | Number of impressions                  |
| `Leads`          | Leads generated                        |
| `Primed Leads`   | Qualified/primed leads generated       |
